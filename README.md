# Вместе — семейный бюджет

Мобильное PWA-приложение для ведения семейного бюджета вдвоём. Работает полностью локально: без регистрации, сервера и банковских интеграций.

## Что реализовано

- главный экран с остатком, дневным лимитом, ближайшим доходом, категориями, покупками и предупреждениями;
- доходы и расходы с категорией, датой, участником, типом бюджета и комментарием;
- быстрый расход и голосовая команда с обязательным подтверждением формы;
- настраиваемые доходы, даты выплат, доли бюджета, участники и категории;
- лимит категории в процентах или фиксированной суммой;
- периоды: календарный месяц, между выплатами или произвольные даты;
- правила переноса остатка, отрицательные остатки и просмотр создавших их операций;
- чек-лист покупок со связью с автоматически созданным расходом;
- переводы между категориями;
- цели накоплений с прогнозом срока;
- графики плана и факта, расходов по дням, распределения, вклада участников и накоплений;
- светлая, тёмная и системная темы;
- экспорт и импорт полной резервной копии в JSON;
- локальное хранение в `localStorage`;
- PWA и офлайн-кэш;
- демонстрационные данные.

## Локальный запуск

Нужен Node.js 20 или новее.

```bash
pnpm install
pnpm run dev
```

Откройте адрес, который покажет Vite. Для проверки production-сборки:

```bash
pnpm run build
pnpm run preview
```

## Установка на iPhone

1. Откройте опубликованное приложение в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».

После первого открытия основные файлы доступны офлайн. Распознавание речи зависит от поддержки браузера и обычно требует интернет-соединения самого браузера.

## Публикация на GitHub Pages

### Простой способ через папку `docs`

Этот способ удобен, если файлы загружаются на GitHub через браузер:

1. Выполните `pnpm run build`. Готовый сайт появится в папке `docs`.
2. Загрузите проект в ветку `main`. Папка `docs` обязательно должна попасть в репозиторий. Папку `node_modules` загружать не нужно.
3. Откройте **Settings → Pages**.
4. В **Build and deployment → Source** выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/docs** и нажмите **Save**.

Нельзя выбирать корень репозитория с исходным `index.html`: этот файл рассчитан на обработку Vite, поэтому напрямую в браузере приложение не запустится.

### Автоматическая публикация через GitHub Actions

1. Создайте репозиторий на GitHub и загрузите проект в ветку `main`, включая скрытую папку `.github`.
2. Откройте **Settings → Pages**.
3. В **Build and deployment → Source** выберите **GitHub Actions**.
4. Запушьте изменения в `main` или запустите workflow **Deploy to GitHub Pages** вручную во вкладке Actions.

Workflow находится в `.github/workflows/deploy.yml`. В Finder скрытые файлы показываются сочетанием `Command + Shift + .`. Конфигурация Vite использует относительный `base`, поэтому приложение работает и в корне домена, и в подпапке репозитория.

## Данные и приватность

Данные находятся только в хранилище текущего браузера. Очистка данных Safari удалит бюджет, поэтому периодически скачивайте резервную копию в **Настройки → Данные → Экспортировать JSON**. Для переноса на другое устройство импортируйте этот файл там же.
